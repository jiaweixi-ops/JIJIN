# 飞书交互约定

## 交易卡片

每笔卡片展示：代码、名称、所属板块、份额类别、金额或份额、订单 ID、版本、数据时间戳、截止时间、卡片有效期、风控状态和理由。

- 买入：红色主题 + `🔴 买入`
- 卖出：绿色主题 + `🟢 卖出`
- 份额/赎回金额在正式净值前使用“预计”标识。

## 自然语言

- `金额加1000`：当前模拟订单增加 1000，生成新版本，旧卡失效并重新风控。
- `卖一半`：改为 50% 比例，生成新版本。
- `为什么`：返回当前订单理由与证据 ID。
- `现在就交易`：进入即时**模拟**复核，不连接真钱交易接口，也不会仅凭一句自然语言完成真实交易。

群聊或多用户场景必须先明确当前订单对象。无法唯一解析“这个/那个”时禁止猜测。

## 权限

- readonly：查询
- editor：查询、修改
- confirmer：查询、修改、模拟确认
- admin：以上全部 + 管理

生产环境必须启用飞书事件验签、verification token、身份映射、回放防护和回调幂等。
