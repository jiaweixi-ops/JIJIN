# V1.3 Phase 6 — Portfolio Risk Visibility

Phase 6 不改变风控规则本身，而是把 Phase 5 已经确定性计算并持久化的组合风险暴露给人类操作者。目标是让“为什么还能买、为什么被挡、还有多少现金/份额被待确认订单占用”可以直接查证，而不是依赖 AI 解释。

## Portfolio Risk API

新增：

```text
GET /portfolio/{account_id}/risk
```

仍要求内部认证。返回内容包括：

- 当前现金、冻结现金、在途现金、已确认基金价值和总资产；
- 每只持仓的份额、最新已确认 NAV、NAV 日期、确认价值和权重；
- 待确认/已批准 BUY 的软预留现金；
- 待确认/已批准 SELL 的软预留份额；
- 尚未完成的 BUY 风险敞口；
- 组合历史峰值、当前回撤、连续亏损天数；
- 当前风控阈值；
- 最近一次正式 `PortfolioSnapshot`；
- 风险标志和 `can_expand_buy_risk`。

该端点是只读观测面，不会修改订单、冻结资产、批准交易或调用模型。

## 估值语义

实时风险看板使用：

```text
latest confirmed NAV on or before business date
```

并明确返回 `valuation_basis`。如果某个当前持仓连可用的 confirmed NAV 都没有，则：

```text
valuation_complete = false
MISSING_CONFIRMED_NAV
```

此处与 22:30 正式日终 `PortfolioSnapshot` 有意不同：正式快照仍要求日期精确匹配的 confirmed NAV；风险看板是日内 as-of 风险视图，不能冒充正式日终收益记录。

## 飞书交易卡

当订单已经完成 Python 风控且 `risk_snapshot.portfolio_risk` 存在时，交易卡会直接展示关键组合指标，例如：

```text
单基金投影：18.00% / 上限 20.00%
当日交易投影：12.00% / 上限 30.00%
组合回撤：5.00% / 保护线 12.00%
连续亏损：2 / 5 天
软预留：已占用 ¥300.00，剩余可用 ¥700.00
```

SELL 卡会显示其他待确认 SELL 已软预留的份额。若组合估值不完整，卡片明确显示警告。

展示层只读取订单已经持久化的风险快照，不让飞书卡重新计算风控，也不让 AI 改写数值。

## 风险标志

当前看板可返回：

```text
MISSING_CONFIRMED_NAV
DRAWDOWN_LIMIT_REACHED
LOSS_STREAK_LIMIT_REACHED
SOFT_RESERVED_CASH_EXCEEDS_AVAILABLE
```

风险标志用于可视化和人工排查；真正是否允许订单通过仍以 `RiskService` 的确定性校验结果为准。

## 边界

Phase 6 不增加：

- 自动实盘；
- 自动批准；
- AI 自主风控；
- 自动修改风险阈值；
- 用风险看板数值替代正式日终账本；
- 独立回测中心。
