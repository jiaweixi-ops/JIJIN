# V1.3 Phase 5 — Portfolio Risk Guardrails

本阶段把已有的组合级风控配置接入确定性 Python 风控链路。它只服务个人研究与前瞻模拟盘，不连接真钱账户，也不会自动批准订单。

## 目标

单笔订单通过自身校验并不代表组合层面可接受。Phase 5 在 `RiskService` 中增加账户级投影，重点解决：

- 多个待确认 BUY 同时占用同一笔可用现金；
- 多个待确认 SELL 同时占用同一批可用份额；
- 新 BUY 使单基金集中度超过上限；
- 当日累计交易量超过账户资产的允许比例；
- 组合已经达到回撤或连续亏损保护阈值后继续扩大 BUY 风险；
- 用旧 NAV 冒充当天正式组合快照。

## 软预留

`PENDING_CONFIRM`、`PENDING_EMERGENCY_CONFIRM`、`APPROVED` 订单尚未全部进入真实模拟账本冻结，因此风控会把它们视为软预留。

BUY：

```text
可用于新 BUY 的现金
= account.available_cash
- 其他未过期待确认/已批准 BUY 的 amount
```

SELL：使用与执行层一致的 FIFO 批次顺序，把其他待确认/已批准 SELL 的 shares 先从 `available_shares` 中虚拟扣除，再对当前订单做 lot allocation。这样不会出现两张卡分别都认为同一份额可卖。

PostgreSQL 风控入口会对账户行使用 `SELECT ... FOR UPDATE`，使同一账户的组合级风险通过与随后状态提交串行化。SQLite 仍是开发/测试的弱并发路径，不作为持续运行环境的并发保证。

## BUY 组合保护

对 BUY 执行以下硬限制：

```text
MAX_SINGLE_FUND_WEIGHT
MAX_DAILY_TRADE_RATIO
MAX_PORTFOLIO_DRAWDOWN
MAX_CONSECUTIVE_LOSS_DAYS
```

单基金权重使用当前已确认组合价值，加上同基金尚未完成的 BUY 风险敞口，再加入当前候选金额进行投影。

当日交易比例把当日已确认 fills 与仍在途/待确认的交易风险敞口一起计算，避免通过多个尚未成交的候选绕过日限额。

若组合中任一当前持仓缺少截至业务日可用的 confirmed NAV，BUY 对集中度/回撤计算 fail-closed，不会凭缺失估值继续放大风险。

## SELL 不被止损保护反向锁死

组合回撤和连续亏损保护的目的，是停止继续增加风险，而不是阻止减仓。因此：

- 回撤达到阈值：阻止 BUY，不阻止 SELL；
- 连续亏损达到阈值：阻止 BUY，不阻止 SELL；
- SELL 导致当日交易比例超过常规阈值：记录 warning，不做组合级硬阻断；
- 原有暂停赎回、份额不足、短持有、适当性、对账阻断等规则仍照常执行。

## PortfolioSnapshot

每日正式快照只接受 `snapshot_date` 精确匹配的 confirmed NAV。

```text
22:30 portfolio_snapshot
```

若任一当前持仓当日 confirmed NAV 尚未到达，例如部分 QDII/FOF 延迟披露，则该账户当日快照保持 pending/跳过，不使用旧 NAV 或估算 NAV 伪造正式 P&L。

第一条可信快照在没有显式 initial capital 时作为绩效基线；后续 `daily_pnl` 使用相邻可信快照的 confirmed assets 计算。

注意：当前版本不会在未来 NAV 到达后自动重建过去某日的历史持仓状态，因此不会做不可靠的历史回填。需要历史精确回填时，应先增加独立的日终持仓快照/事件重放能力。

## 审计

每次 operational risk pass/reject 会把 `portfolio_risk` 写入订单 `risk_snapshot`，包括：

- 总已确认资产；
- 估值是否完整与缺失 NAV 基金；
- BUY 软预留现金；
- SELL 软预留份额；
- 当前基金价值与同基金 pending BUY；
- 投影单基金权重；
- 当日交易价值与投影交易比例；
- 历史峰值资产与当前回撤；
- 连续亏损天数。

因此后续复核可以解释“为什么当时通过/拒绝”，而不是只保存一个布尔结果。

## 配置校验

启动时要求：

```text
0 < MAX_SINGLE_FUND_WEIGHT <= 1
0 < MAX_DAILY_TRADE_RATIO <= 1
0 < MAX_PORTFOLIO_DRAWDOWN <= 1
MAX_CONSECUTIVE_LOSS_DAYS >= 1
```

如希望近似关闭某个比例限制，应显式设为 `1`，而不是 `0`。

## 非目标

本阶段不增加：

- 自动实盘；
- 自动批准；
- AI 自主修改风控阈值；
- 独立回测中心；
- 用估算 NAV 进入正式账本或正式收益统计。
